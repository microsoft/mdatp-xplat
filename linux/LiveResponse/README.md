# Live Response Scripts

This is a collection of scripts for Live Response sessions on Linux machines.

## Client Analyzer

These self-contained actions install and run Client Analyzer through a private
verified workspace. Each action can be uploaded independently to Live Response.
See [Client Analyzer](ClientAnalyzer/README.md) and [Microsoft Learn: Run the client analyzer on Linux](https://learn.microsoft.com/en-us/defender-endpoint/run-analyzer-linux).
